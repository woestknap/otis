Otis features

Expressive companion shell with room for sensors, light, touch, and playful interaction states.

Keychain hole

A small carry point built into the shell for attaching Otis to a bag, keyring, or display loop.

Base station

Docking concept for charging, pairing, and the upcoming connection animation between Otis and the base.

Touch button

Primary tactile input for waking Otis, confirming actions, and starting simple interaction loops.
